# Windows Terminal

## 1. O que é

O Windows Terminal é o app moderno que reúne PowerShell, Prompt de Comando e WSL em abas, com temas e fontes personalizadas.

## 2. Para quem serve

Todo mundo que usa a linha de comando, de iniciantes a devs.

## 3. O que muda na sua tela

As janelas de terminal ganham abas, esquemas de cores, transparência e fonte personalizada.

## 4. Primeiros passos depois de ativar

Abra pelo menu Iniciar e pressione Ctrl + , para abrir as Configurações. Escolha um esquema de cores em Aparência.

## 5. Atalhos principais

Veja a aba Atalhos.

## 6. Personalizações comuns

Troque o esquema de cores, a fonte (uma Nerd Font funciona melhor com o Oh My Posh) e a opacidade do fundo.

## 7. Problemas comuns e soluções

Ícones aparecem como quadradinhos: escolha uma Nerd Font em Configurações > Perfis > Aparência.

## 8. Como desfazer

O WinRice faz backup do settings.json antes de mudar; restaure pela página Histórico.
