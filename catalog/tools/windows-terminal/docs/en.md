# Windows Terminal

## 1. What it is

Windows Terminal is the modern app that hosts PowerShell, Command Prompt and WSL in tabs, with themes and custom fonts.

## 2. Who it's for

Everyone who uses the command line, from beginners to developers.

## 3. What changes on your screen

Terminal windows get tabs, color schemes, transparency and a custom font.

## 4. First steps after enabling

Open it from the Start menu and press Ctrl + , to open Settings. Pick a color scheme under Appearance.

## 5. Main shortcuts

See the Shortcuts tab.

## 6. Common customizations

Change the color scheme, font (a Nerd Font works best with Oh My Posh) and background opacity.

## 7. Common problems

Icons look like boxes: choose a Nerd Font in Settings > Profiles > Appearance.

## 8. How to undo

WinRice backs up settings.json before changing it; restore it from the History page.
