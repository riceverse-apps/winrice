# Nilesoft Shell

## 1. What it is

Nilesoft Shell lets you rebuild the Windows right-click menu with your own items, icons and styles.

## 2. Who it's for

Advanced users who want a cleaner, faster context menu.

## 3. What changes on your screen

The right-click menu is replaced by a configurable one.

## 4. First steps after enabling

After installing, edit `shell.nss` in its install folder and reload.

## 5. Main shortcuts

No shortcuts of its own.

## 6. Common customizations

Everything is defined in `shell.nss`.

## 7. Common problems

Menu looks broken: uninstall and check `shell.nss` for typos.

## 8. How to undo

Uninstall it from the tool page.
