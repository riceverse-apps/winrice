# Flow Launcher

## 1. O que é

O Flow Launcher é uma caixa de busca que você abre com um atalho para abrir apps, achar arquivos, fazer contas e buscar na web.

## 2. Para quem serve

Quem quer abrir as coisas rápido sem usar o mouse.

## 3. O que muda na sua tela

Uma caixa de busca aparece no meio da tela ao pressionar Alt + Espaço.

## 4. Primeiros passos depois de ativar

Pressione Alt + Espaço e digite o nome de um app. Abra as configurações para adicionar plugins.

## 5. Atalhos principais

Veja a aba Atalhos.

## 6. Personalizações comuns

Mude o atalho, o tema e os plugins instalados nas configurações.

## 7. Problemas comuns e soluções

O atalho não funciona: outro app (como o PowerToys Run) usa Alt + Espaço. Mude um dos dois.

## 8. Como desfazer

Desative no toggle.
