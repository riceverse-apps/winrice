# GlazeWM

## 1. What it is

GlazeWM is a *tiling window manager*: instead of you dragging windows around, it places them side by side automatically. You control it with the keyboard.

## 2. Who it's for

People who work with many windows at once and like keyboard shortcuts, and developers who want a Linux-style setup.

## 3. What changes on your screen

Windows snap into a grid without overlapping. The focused window gets a colored border.

## 4. First steps after enabling

Open a few apps and use Alt + H/J/K/L to move between them. The config file lives in `%USERPROFILE%\.glzr\glazewm\config.yaml`.

## 5. Main shortcuts

See the Shortcuts tab.

## 6. Common customizations

Edit `gaps` for spacing between windows and add rules so games or small dialogs float.

## 7. Common problems

A game or fullscreen app gets tiled: add a `window_rules` entry that sets it to floating.

## 8. How to undo

Turn off the toggle or press Alt + Shift + E. Your original config is backed up before any change.
