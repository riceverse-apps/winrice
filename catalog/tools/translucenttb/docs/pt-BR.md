# TranslucentTB

## 1. O que é

O TranslucentTB deixa a barra de tarefas do Windows transparente ou desfocada. É o jeito mais fácil de ter uma área de trabalho mais limpa.

## 2. Para quem serve

Iniciantes que querem uma mudança visual rápida.

## 3. O que muda na sua tela

A barra de tarefas fica transparente, desfocada ou colorida.

## 4. Primeiros passos depois de ativar

Ative e clique com o botão direito no ícone da bandeja para escolher o estilo.

## 5. Atalhos principais

Sem atalhos próprios.

## 6. Personalizações comuns

Aparências diferentes para normal, janela maximizada, menu Iniciar aberto e busca aberta.

## 7. Problemas comuns e soluções

Nada muda: confira se o ícone da bandeja está visível. Pode parar após reiniciar o Explorer; ligue de novo.

## 8. Como desfazer

Desative no toggle; a barra de tarefas volta ao normal.
