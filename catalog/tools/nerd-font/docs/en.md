# Nerd Fonts (JetBrainsMono)

## 1. What it is

A Nerd Font is a normal font with thousands of extra icons used by prompts and status bars.

## 2. Who it's for

Anyone using Oh My Posh, Starship, YASB or similar tools.

## 3. What changes on your screen

Nothing changes by itself; after you pick the font in your terminal, icons show correctly.

## 4. First steps after enabling

After installing, open Windows Terminal settings and choose *JetBrainsMono Nerd Font* as the font.

## 5. Main shortcuts

No shortcuts of its own.

## 6. Common customizations

Use it in Windows Terminal, VS Code and your status bar.

## 7. Common problems

Icons still look like boxes: select the font in your terminal profile and restart it.

## 8. How to undo

Uninstall it from the tool page.
