# Nerd Fonts (JetBrainsMono)

## 1. O que é

Uma Nerd Font é uma fonte comum com milhares de ícones extras usados por prompts e barras de status.

## 2. Para quem serve

Quem usa Oh My Posh, Starship, YASB ou ferramentas parecidas.

## 3. O que muda na sua tela

Nada muda sozinho; depois de escolher a fonte no terminal, os ícones aparecem corretamente.

## 4. Primeiros passos depois de ativar

Depois de instalar, abra as configurações do Windows Terminal e escolha *JetBrainsMono Nerd Font* como fonte.

## 5. Atalhos principais

Sem atalhos próprios.

## 6. Personalizações comuns

Use no Windows Terminal, no VS Code e na sua barra de status.

## 7. Problemas comuns e soluções

Os ícones continuam como quadradinhos: selecione a fonte no perfil do terminal e reinicie.

## 8. Como desfazer

Desinstale pela página da ferramenta.
