# Seelen UI

## 1. O que é

O Seelen UI é um ambiente de desktop completo para o Windows, com barra, dock, lançador de apps e mosaico.

## 2. Para quem serve

Quem quer um desktop parecido com o macOS sem montar várias ferramentas.

## 3. O que muda na sua tela

Aparecem uma barra no topo e uma dock, e as janelas podem ser organizadas em mosaico.

## 4. Primeiros passos depois de ativar

Ative e abra as configurações pelo ícone da bandeja para escolher layouts e temas.

## 5. Atalhos principais

Sem atalhos próprios.

## 6. Personalizações comuns

Itens da barra, apps da dock, layouts de mosaico e temas.

## 7. Problemas comuns e soluções

Não use junto com outra barra ou gerenciador de mosaico.

## 8. Como desfazer

Desative no toggle.
