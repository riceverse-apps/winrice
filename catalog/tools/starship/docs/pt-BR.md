# Starship

## 1. O que é

O Starship é um prompt rápido para o terminal que mostra informações úteis, como o branch do git.

## 2. Para quem serve

Quem usa PowerShell e quer um prompt mais bonito, como alternativa ao Oh My Posh.

## 3. O que muda na sua tela

O prompt do PowerShell mostra pasta, branch do git e versões de linguagens.

## 4. Primeiros passos depois de ativar

Ative e abra uma nova janela do PowerShell. Uma Nerd Font mostra todos os ícones.

## 5. Atalhos principais

Sem atalhos próprios.

## 6. Personalizações comuns

Tudo é configurado no `starship.toml`.

## 7. Problemas comuns e soluções

Não pode ficar ligado junto com o Oh My Posh. Ícones como quadradinhos: instale uma Nerd Font.

## 8. Como desfazer

Desative no toggle; as linhas adicionadas são removidas.
