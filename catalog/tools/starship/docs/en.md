# Starship

## 1. What it is

Starship is a fast prompt for your terminal that shows useful information such as the git branch.

## 2. Who it's for

Anyone who uses PowerShell and wants a nicer prompt, as an alternative to Oh My Posh.

## 3. What changes on your screen

The PowerShell prompt shows folder, git branch and language versions.

## 4. First steps after enabling

Enable it and open a new PowerShell window. A Nerd Font shows all icons.

## 5. Main shortcuts

No shortcuts of its own.

## 6. Common customizations

Everything is configured in `starship.toml`.

## 7. Common problems

Cannot be on together with Oh My Posh. Icons as boxes: install a Nerd Font.

## 8. How to undo

Turn off the toggle; the added lines are removed.
