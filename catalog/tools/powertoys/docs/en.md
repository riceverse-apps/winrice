# PowerToys

## 1. What it is

PowerToys is a set of small utilities by Microsoft, including FancyZones (custom window layouts) and PowerToys Run (a launcher).

## 2. Who it's for

Anyone who wants more productivity without changing the look.

## 3. What changes on your screen

New utilities become available, such as snapping windows into custom zones.

## 4. First steps after enabling

Enable it and open PowerToys settings from the tray to switch modules on or off.

## 5. Main shortcuts

No shortcuts of its own.

## 6. Common customizations

FancyZones layouts, Run shortcuts, keyboard remapping.

## 7. Common problems

Alt + Space clash with Flow Launcher: change one of the shortcuts.

## 8. How to undo

Turn off the toggle.
