# Oh My Posh

## 1. What it is

Oh My Posh makes your PowerShell prompt informative and pretty: current folder, git branch, errors and icons.

## 2. Who it's for

People who use PowerShell often and want a nicer prompt.

## 3. What changes on your screen

Only the text before your cursor in PowerShell changes.

## 4. First steps after enabling

Enable it, then open a new PowerShell window. Install a Nerd Font and select it in your terminal to see all icons.

## 5. Main shortcuts

None.

## 6. Common customizations

Choose another prompt theme from the official theme list and point your profile to it.

## 7. Common problems

Icons look like boxes: install a Nerd Font. Prompt not changing: open a new PowerShell window.

## 8. How to undo

Turn off the toggle; WinRice removes the lines it added to your profile (a backup was made first).
