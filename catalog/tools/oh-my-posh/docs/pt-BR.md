# Oh My Posh

## 1. O que é

O Oh My Posh deixa o prompt do PowerShell informativo e bonito: pasta atual, branch do git, erros e ícones.

## 2. Para quem serve

Quem usa o PowerShell com frequência e quer um prompt mais agradável.

## 3. O que muda na sua tela

Só muda o texto antes do cursor no PowerShell.

## 4. Primeiros passos depois de ativar

Ative e abra uma nova janela do PowerShell. Instale uma Nerd Font e selecione no terminal para ver todos os ícones.

## 5. Atalhos principais

Nenhum.

## 6. Personalizações comuns

Escolha outro tema de prompt na lista oficial e aponte seu perfil para ele.

## 7. Problemas comuns e soluções

Ícones aparecem como quadradinhos: instale uma Nerd Font. Prompt não mudou: abra uma nova janela do PowerShell.

## 8. Como desfazer

Desative no toggle; o WinRice remove as linhas que adicionou ao seu perfil (um backup foi feito antes).
