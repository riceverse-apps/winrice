# YASB Reborn

## 1. O que é

O YASB é uma barra de status personalizável para o Windows, estilizada com CSS e configurada em um arquivo YAML.

## 2. Para quem serve

Quem quer uma barra no topo no estilo macOS/Linux.

## 3. O que muda na sua tela

Aparece uma barra no topo da tela com relógio, áreas de trabalho e widgets do sistema.

## 4. Primeiros passos depois de ativar

Instale uma Nerd Font, ative o YASB e edite o `config.yaml` em `.config\yasb`.

## 5. Atalhos principais

Sem atalhos próprios.

## 6. Personalizações comuns

Widgets no `config.yaml`; cores e fontes no `styles.css`.

## 7. Problemas comuns e soluções

Ícones como quadradinhos: instale uma Nerd Font. Barra escondida atrás da barra de tarefas: esconda a barra com um mod do Windhawk.

## 8. Como desfazer

Desative no toggle; a barra fecha.
