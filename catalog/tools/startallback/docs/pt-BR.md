# StartAllBack

## 1. O que é

O StartAllBack personaliza a barra de tarefas, o menu Iniciar e o Explorador de Arquivos do Windows 11 para o visual clássico. É um software pago, com teste grátis.

## 2. Para quem serve

Quem quer um visual clássico bem acabado e aceita pagar por isso.

## 3. O que muda na sua tela

Barra de tarefas, menu Iniciar e Explorer ganham o visual clássico do Windows 7/10.

## 4. Primeiros passos depois de ativar

Depois de instalar, abra o StartAllBack pelo menu Iniciar e escolha um estilo.

## 5. Atalhos principais

Sem atalhos próprios.

## 6. Personalizações comuns

Tamanho e posição da barra de tarefas, layout do menu Iniciar, barra do Explorer.

## 7. Problemas comuns e soluções

Não funciona com ExplorerPatcher nem Start11. Após uma atualização do Windows, atualize o StartAllBack.

## 8. Como desfazer

Desinstale pela página da ferramenta.
