# Start11

## 1. What it is

Start11 from Stardock lets you pick a different Start menu and taskbar style. It is paid software with a free trial.

## 2. Who it's for

People who want a different Start menu and accept paying for it.

## 3. What changes on your screen

The Start menu and taskbar take the style you choose.

## 4. First steps after enabling

Open Start11 from the Start menu and choose a Start style.

## 5. Main shortcuts

No shortcuts of its own.

## 6. Common customizations

Start menu style, taskbar position and size, search box.

## 7. Common problems

It cannot run together with StartAllBack.

## 8. How to undo

Uninstall it from the tool page.
