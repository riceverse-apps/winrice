# ExplorerPatcher

## 1. What it is

ExplorerPatcher changes how the Windows 11 taskbar, Start menu and File Explorer behave, for example bringing back the classic taskbar.

## 2. Who it's for

Advanced users who prefer the Windows 10 look.

## 3. What changes on your screen

The taskbar and Start menu look like Windows 10 (or Windows 11 variants you choose).

## 4. First steps after enabling

After installing, right-click the taskbar and open *Properties* to choose options.

## 5. Main shortcuts

No shortcuts of its own.

## 6. Common customizations

Taskbar style, Start menu style, system tray and File Explorer options.

## 7. Common problems

After a Windows update it may stop working: reinstall the latest version. It cannot be used with StartAllBack.

## 8. How to undo

Uninstall it from the tool page; WinRice's watchdog also reverts a crash loop right after enabling.
