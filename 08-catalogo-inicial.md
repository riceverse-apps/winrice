# 08 — Catálogo Inicial de Ferramentas (v1)

Antes de criar cada manifesto, o agente deve **confirmar na fonte oficial**: método de instalação atual (id do winget), licença, builds suportadas e caminho das configs. Não confiar só nesta lista.

## Window managers (tiling)
| id | Ferramenta | Observação |
|---|---|---|
| glazewm | GlazeWM | Inspirado no i3, config YAML, traz Zebar opcional |
| komorebi | Komorebi | Mais leve; **verificar licença** (restrições para uso comercial) |

## Barras de status
| id | Ferramenta | Observação |
|---|---|---|
| zebar | Zebar | Par natural do GlazeWM |
| yasb | YASB Reborn | Python, config YAML + CSS, exige Nerd Font |

## Taskbar / Start / Explorer
| id | Ferramenta | Observação |
|---|---|---|
| windhawk | Windhawk | Plataforma de mods; o app deve gerenciar **mods individuais** como subitens |
| explorerpatcher | ExplorerPatcher | Grátis; sensível a updates do Windows |
| startallback | StartAllBack | Pago (trial) — sinalizar na UI |
| start11 | Start11 | Pago — sinalizar na UI |
| translucenttb | TranslucentTB | Taskbar transparente, para iniciantes |
| seelen-ui | Seelen UI | Ambiente completo (barra, dock, tiling) |

## Terminal
| id | Ferramenta | Observação |
|---|---|---|
| windows-terminal | Windows Terminal | Gerenciar esquemas de cores e perfil |
| oh-my-posh | Oh My Posh | Prompt customizado |
| starship | Starship | Alternativa ao Oh My Posh (conflito lógico: só um prompt ativo) |
| nerd-font | Nerd Fonts | Instalar fontes (JetBrainsMono, CaskaydiaCove) |
| fastfetch | Fastfetch | Info do sistema no terminal |
