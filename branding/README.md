# Branding

Logos of the Riceverse family: **WinRice**, **MacRice** and **LinuxRice**. All three share the same rice-grain symbol; only the accent color and one small detail change (see `14-identidade-visual.md`).

| File | Use |
|---|---|
| `winrice-logo-1024.png`, `macrice-logo-1024.png`, `linuxrice-logo-1024.png`, `riceverse-logo-1024.png` | the four logos (Windows, macOS, Linux, the organization), 1024x1024 with transparent corners |
| `logo-mark-1024.png`, `icon.ico`, `tauri-icons/` | WinRice icon and every size the installer, taskbar and tray need (the tray uses the app icon) |
| `avatar-github.png` | avatar of the GitHub organization (opaque, because GitHub crops it to a circle) |
| `social-preview*.png` | 1280x640 images for each repository's *Social preview* |

The site and the app use `logo-mark.png` and `favicon.ico`, copied from here.

## Rule: no third-party marks

Do **not** add the Windows logo, the Apple logo, or anything that imitates them, and do not use the exact brand colors of those companies as the main color. The icons keep the shared rice-grain symbol and only change the accent color and one detail: stacked glass panes for WinRice, a petal for MacRice, a stylized penguin for LinuxRice. In the organization logo the system hints are generic glyphs (a window, a petal) and the penguin. Earlier versions with the real logos were removed from the repository history on purpose.
