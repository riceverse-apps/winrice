# Branding

Logos of the Riceverse family: **WinRice**, **MacRice** and **LinuxRice**. All three share the same rice-grain symbol; only the accent color and one small detail change (see `14-identidade-visual.md`).

| File | Use |
|---|---|
| `winrice-logo-1024.png`, `macrice-logo-1024.png`, `linuxrice-logo-1024.png` | app logos, 1024x1024 with transparent corners |
| `logo-mark-1024.png`, `logo-mark.svg`, `icon.ico`, `tauri-icons/` | WinRice icon and the sizes the installer needs |
| `avatar-github.png` | avatar of the GitHub organization |
| `social-preview*.png` | 1280x640 images for each repository's *Social preview* |
| `tray-light.svg`, `tray-dark.svg` | tray icons |

## Rule: no third-party marks

Do **not** add the Windows logo, the Apple logo, the Tux penguin, or anything that imitates them, and do not use the exact brand colors of those companies as the main color. Logos with these shapes were removed from the repository history on purpose. The distinguishing detail of each app is abstract: a glow dot for MacRice and a `>_` prompt for LinuxRice.
